
# Ο Κουκλόκοσμος 🎭

Ένας μαγικός κόσμος όπου οι κούκλες ζωντανεύουν!

Website για τη θεατρική παράσταση «Ο Κουκλόκοσμος».

## Τεχνολογίες

- HTML5
- CSS3
- Vanilla JavaScript

Το website είναι 100% στατικό.

Δεν απαιτεί backend, βάση δεδομένων,
npm ή build process.

## Εκτέλεση τοπικά

Άνοιξε το `index.html` στον browser.

Εναλλακτικά, μπορείς να χρησιμοποιήσεις
έναν τοπικό HTTP server:

```bash
python3 -m http.server 8000
```

Έπειτα άνοιξε:

http://localhost:8000

Το website μπορεί να δημοσιευτεί δωρεάν
μέσω GitHub Pages, Netlify ή Vercel.

Το publish directory είναι το root
του repository.
